# Boris Theatre - Customer Management System (Java)

Component Developer: Ranjit (CTEC2713 Agile Development Team Project)

## How to Run in VS Code
1. Extract this ZIP folder completely.
2. Open the extracted `BorisTheatre_CustomerManagement_Java` folder in VS Code.
3. Open the VS Code Terminal (`Ctrl + ~`).
4. Run:
   ```powershell
   javac src/*.java
   java -cp src WebServerApp
   ```
5. Open your browser at `http://localhost:8080`.
